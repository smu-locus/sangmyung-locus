# LOCUS

**강원·충청·전라·경상, 한국의 지역 여행지를 한국어·영어·일본어로 소개하는 로컬 여행 아카이브**

🔗 **사이트 바로가기: https://smu-locus.github.io/sangmyung-locus/**

서버나 데이터베이스 없이 동작하는 정적 웹사이트입니다. 팀원들이 Markdown 문서로 여행지 자료를 쓰면, 빌드 과정에서 자료가 데이터로 바뀌고 3개 국어 사이트가 자동으로 만들어집니다. `main` 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다.

| 규모 | |
|---|---|
| 여행지 | 219곳 (4개 지역, 5개 테마) |
| 여행자 지원 정보 | 숙박 55곳 · 의료시설 52곳 · 관광안내소 37곳 · Q&A |
| 언어 | 한국어 · English · 日本語 (화면 문구와 자료 본문 모두) |
| 페이지 | 13개 |

## 주요 기능

### 여행지 탐색
- **로컬 스팟**: 지역 탭으로 고르고, 북도·남도가 나뉜 지역(경상·전라·충청)은 한 번 더 좁혀 볼 수 있습니다. 지역마다 소개글과 함께, 그 지역이 표시된 미니 지도가 나옵니다.
- **테마 아카이브**: 쇼핑, 엔터테인먼트, 역사, 음식, 자연관광 중 하나를 골라 테마별 여행지를 봅니다.
- **여행지 상세**: 기본 정보(주소, 영업시간, 입장료, 주차, 대중교통 등)와 사진 갤러리, Google 지도를 보여줍니다. 비어 있는 항목은 자동으로 숨깁니다.

### 큐레이션
- **K-컬쳐 Pick**: 드라마·영화 촬영지 같은 K-컬쳐 여행지를 모았습니다. 메인 화면에서는 한국 지도 위에 지역별 카드를 연결선으로 보여주고, 지역을 누르면 그 지역의 K-컬쳐 Pick으로 이동합니다.
- **에디터's Pick**: 팀원들이 직접 다녀온 여행을 블로그 글처럼 소개하는 코너입니다.
- **여행 MBTI**: 몇 가지 질문에 답하면 여행 취향 유형과 어울리는 여행지를 추천합니다.
- **랜덤 여행지 Pick**: 갈 곳을 못 정했을 때 제비뽑기처럼 여행지를 뽑아 줍니다.

### 여행자 지원
- 숙박, 의료시설, 관광안내소를 지역별로 찾을 수 있고, 자주 묻는 질문(Q&A)을 주제별로 모았습니다.

### 사용 환경
- **3개 국어**: 화면 상단에서 언어를 바꾸면 메뉴, 버튼, 여행지 본문, 메인 슬라이드 사진까지 바뀝니다. 고른 언어는 기억해 두고, 번역이 없는 항목은 한국어로 보여줍니다.
- **모바일 대응**: 휴대폰 화면에서도 지도와 카드, 메뉴가 화면 폭에 맞게 배치됩니다.
- **파비콘과 홈 화면 아이콘**: 일반 브라우저 탭, 다크 모드, iPhone 홈 화면, Android, Windows 타일, Safari 고정 탭까지 대비했습니다.

## 기술적으로 신경 쓴 부분

**비개발자가 자료를 쓰고, 코드가 알아서 정리하는 구조**
자료를 쓰는 사람은 Markdown만 다룹니다. 빌드 스크립트(Python)가 370여 개 문서를 읽어 종류(관광지, 숙박, 의료 등)와 지역, 테마를 판별하고 언어별 JSON 데이터로 만듭니다. 사람이 쓰다 보니 생기는 차이도 흡수합니다.
- 폴더 이름이 한글이어도 됩니다.
- `자연`, `자연경관`처럼 표기가 달라도 같은 테마로 맞춥니다.
- `대지역`이 빠지면 주소로 지역을 짐작합니다.
- 같은 장소 파일이 두 폴더에 있으면 하나로 합칩니다.
- 그래도 판별이 안 되는 파일은 빌드가 끝날 때 목록으로 알려줘서, 그 파일만 고치면 됩니다.

**번역이 빠져도 깨지지 않는 다국어 처리**
영어·일본어 파일은 번역문만 담고, 지역·사진·지도 같은 공통 값은 한국어 원본에서 가져옵니다. 번역 파일이나 항목이 없으면 그 부분만 한국어로 보여주기 때문에, 번역이 덜 끝난 상태에서도 사이트는 정상적으로 동작합니다.

**의존성 없는 가벼운 프런트엔드**
프레임워크 없이 TypeScript로 작성했고, 개발 도구도 TypeScript 하나만 씁니다. 페이지마다 HTML은 빈 틀이고, 주소의 조건(`?region=`, `?theme=` 등)에 따라 스크립트가 데이터를 골라 화면을 그립니다. 한국 지도는 SVG로 직접 그려서 지역 연결선, 클릭 동작, 반응형 배치를 자유롭게 조정할 수 있습니다.

**배포 환경에서도 그대로 동작**
- 사이트가 하위 경로(`/sangmyung-locus/`)에 배포되기 때문에, 모든 경로를 상대 경로로 맞췄습니다.
- 외부 사진이 막히면 다음 사진으로 넘어가도록 대체 경로를 두었습니다.
- 수정한 CSS와 JS가 사용자 브라우저에 바로 적용되도록 버전 번호로 캐시를 관리합니다.

## 구조

```
content/{ko,en,ja}/   여행지 자료 (Markdown, 언어별로 같은 구조)
        │
        ▼  build_travel_index.py
dist/data/*.json      언어별 여행지 데이터
        │
        ▼  src/ts/*.ts (TypeScript → JavaScript)
dist/                 완성된 정적 사이트 → GitHub Pages
```

| 경로 | 내용 |
|---|---|
| `content/` | 원본 자료. 지역 › 종류(로컬 스팟, K-컬쳐, 숙박 등) 순서의 폴더 구조 |
| `src/ts/` | 화면 생성과 동작(`script.ts`), 3개 국어 문구(`i18n.ts`), 지도 데이터 |
| `src/pages/` | 페이지별 HTML 틀 |
| `src/styles/` | 디자인 |
| `public/` | 로고, 메인 슬라이드, 파비콘 등 정적 파일 |
| `.github/workflows/` | 자동 빌드·배포 설정 |

## 직접 실행해 보기

**Node.js**와 **Python 3.8 이상**이 필요합니다.

```bash
npm install      # 처음 한 번
npm run build    # dist/에 사이트 생성
npm run serve    # http://localhost:8000 에서 확인
```

`dist/index.html`을 파일로 바로 열면 브라우저 보안 정책 때문에 데이터를 불러오지 못합니다. `npm run serve`로 띄운 주소에서 확인해 주세요.
